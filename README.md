# RF 기술이슈 관리 시스템

고객사에서 발생한 **RF Generator / RF Matcher(Matching Box) 및 기타 장비**의 기술 이슈를
등록·검색하고, 사내 공유폴더의 기술자료와 연결해 **현장에서 몇 초 안에 대응 방법을 찾는**
사내 전용 도구입니다.

Node.js 만 있으면 도는 단일 프로세스 웹 서버입니다. 검색·색인·저장이 모두 사내 PC 안에서
이루어지고, 바깥으로 나가는 통신이 없습니다.

---

## 주요 기능

| 기능 | 설명 |
|---|---|
| **통합검색** | 이슈 · 지식/용어 · 자료 파일을 검색어 하나로 동시에 찾습니다 |
| **연관어 사전** | "쿨링워터"라고 해도 "냉각수" 자료가 나옵니다 |
| **음성 검색** | 검색창의 🎤 버튼 (Chrome · Edge) |
| **이슈 관리** | 증상 · 원인 · 조치 · 재발방지를 기록하고 관련 자료를 연결합니다 (CSV 내보내기 지원) |
| **지식맵** | 분류별로 자료를 훑어봅니다 |
| **자동 재색인** | 원본 엑셀이 바뀌면 스스로 다시 읽어 들입니다 |
| **작업 일지 백업** | 정해진 주기마다, 그리고 종료할 때 공유폴더에 날짜별로 남깁니다 |

---

## 실행

1. Node.js LTS 설치
2. `config.example.json` 을 복사해 `config.json` 으로 만들고, 사내 공유폴더 경로와 포트를 채웁니다
3. `RF이슈관리 시작.bat` 더블클릭 → <http://localhost:7331>

처음 실행할 때는 공유폴더를 훑어 색인을 만드느라 1~3분 걸립니다.
색인만 다시 만들려면 `node tools/build-kb.js` 를 실행하세요.

## 구성

```
server.js                 웹 서버 · 검색 · 이슈 API
public/                   화면 (index.html · app.js · style.css)
tools/
  build-kb.js             공유폴더와 엑셀을 훑어 색인 생성
  parse-xlsx.js           엑셀 읽기 (셀 메모 포함)
  excel-sig.js            원본 엑셀이 바뀌었는지 판단
  backup.js               작업 일지를 공유폴더에 날짜별로 백업
  build-worklog.js        README 의 최근 작업 일지 갱신
  check-secrets.js        커밋 전 사내 정보 검사
  install-hooks.js        위 검사를 커밋 훅으로 설치
  smoke-ui.js · zip.js    점검 · 압축 보조
data/                     색인 · 이슈 · 연관어 (저장소에 올리지 않음)
사용설명서.md              전체 사용법
```

## 사내 정보 취급

이 저장소는 공개(public)입니다. 사내 정보가 한 번 올라가면 이력에서 지우기 어려우므로
두 겹으로 막습니다.

- **`.gitignore`** — 색인, 이슈 원본, 고객사 명단, 설정 파일을 저장소에서 제외합니다
- **커밋 전 검사** — `tools/check-secrets.js` 가 사설 IP · 공유폴더 경로 · 발주 번호 ·
  고객사명 · 토큰이 섞였는지 확인하고, 걸리면 커밋을 멈춥니다

```
node tools/install-hooks.js     # 커밋할 때 자동으로 검사되도록 설치
node tools/check-secrets.js     # 지금 스테이징된 내용만 검사
```

자세한 사용법은 [사용설명서.md](사용설명서.md) 를 보세요.
